# 展示范围

## 本仓库提供

- 周期池、策略生成、模拟评估、冠军库与并行交易竞争的总体流程和组件职责。
- 专门为展示编写的信号数据结构与内存模拟账户。
- 固定虚拟事件和终端演示。
- 围绕一个具体问题开展研究的协作方式。

## 本仓库不包含

- 周期池配置、策略生成算法、筛选及排名细则。
- 生产决策算法、真实计算参数及训练或学习状态。
- 生产代码目录、数据库结构、部署文件及运行日志。
- 原始市场输入与内部计算中间值的配对样本。
- 真实信号、真实订单与账户记录。
- 实盘连接、交易凭据或可以调用内部系统的入口。

演示值不是生产值的缩放、扰动或时间平移版本。虚拟事件的顺序与数量也不代表真实开仓频率。

公开的组件关系仍会透露项目的大体思路。本仓库的目标是控制披露范围，不声称能够保证任何形式的推断均不可能。
