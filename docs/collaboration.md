# 寻找共同研发的合伙人

希望找到懂交易、能够独立判断、愿意共同研究和验证策略的合伙人。先从一个范围明确的问题开始，了解彼此的投入和工作方式。

当前项目处在开发验证阶段。合作重点是研究交易规则、复核数据和改进程序。具体分工、投入、费用与成果归属，根据实际合作另行约定。

## 可以讨论的方向

| 方向 | 可交付的结果 |
| --- | --- |
| 行情质量 | 缺失、重复、异常值和时间对齐的核验方法 |
| 入场条件 | 明确的条件定义、适用场景和失败案例 |
| 费用归因 | 对费用、价差和滑点影响的可复核计算 |
| 实验核验 | 数据范围、可用时间、信号与成交数量的逐项解释 |
| 工程质量 | 可恢复运行、错误定位和展示可读性的改进 |

## 研究提案应说明

1. 想解决的具体问题及其证据。
2. 需要哪些数据，以及数据在当时是否已经可用。
3. 哪些规则保持固定，哪些变量准备调整。
4. 如何计入交易成本、账户约束和样本差异。
5. 用什么标准判断改善、无效或无法下结论。

首次协作不要求访问完整生产系统。针对任务提供必要的研究材料；扩大访问范围与合作权益，需要双方另行确认。

公开问题讨论中不要上传账户资料、凭据或第三方未授权数据。尚未核验的结果应明确标注，不能当作实盘业绩。
